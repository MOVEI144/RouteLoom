### DevRam と host API

- 既定 C3 bridge image は `esp_wifi_init failed` で 30 分 sleep。Wi-Fi buffer 縮小だけでは `phy_init: failed to allocate memory for RF calibration data`。dedup profile を relay 96→leaf 32 にした軽量 image は起動し、Wi-Fi 前 heap `free=37,644, largest=34,816` B。これは**既定構成の合格ではない**。[既定失敗](../../artifacts/hil/2026-09-26/flash-usbdiag/flash-bridge-boot.log)、[軽量起動](../../artifacts/hil/2026-09-26/flash-original-lowmem/flash-bridge-boot.log)。
- Node2/3 は互いに BOUND/REACHABLE。軽量 Node1/2 の [bind HIL](../../artifacts/hil/2026-09-26/scenarios/20260925-164630-bench-2026-09-26-lowmem-bind/report.json) は 6.2 秒で PASS。[初回 send](../../artifacts/hil/2026-09-26/scenarios/20260925-164640-bench-2026-09-26-lowmem-delivery/report.json) は `queued frame session changed` で FAIL。host legacy SEND が起動 ID を USB session 欄に入れたバグを修正し、[再試験](../../artifacts/hil/2026-09-26/scenarios/20260925-165048-bench-2026-09-26-sessionfix-delivery/report.json) で `delivered / END_RECEIVED` と reference の `message origin=1` を確認した。
- [status/nodes/node-get/diagnostics](../../artifacts/hil/2026-09-26/devram-host-recovered-readonly.log): 認証済み、protocol error 0。`nodes` は capability bit 不足で source=`unsupported`、`node-get` は `NOT_FOUND`。既定 DevRam `group-send` も [UNSUPPORTED](../../artifacts/hil/2026-09-26/devram-group-default.log)。別の LegacyFixture/gateway-scoped image では [nodes と 1 hop RSSI](../../artifacts/hil/2026-09-26/group-legacy-host-readonly.log)、[group-send 1/1](../../artifacts/hil/2026-09-26/group-legacy-outcome.json) を確認した。
- [legacy send 100 試行](../../artifacts/hil/2026-09-26/devram-100send-recovered.summary.json): accepted 15、端末受領 14、1 件 `IDEMPOTENCY_FULL`、85 件 host rate limited。受理→受領 14 件の中央値 104.67 ms、p95 207.90 ms、最大 209.39 ms。**100 件の無線成功率ではない**。[submit 20 件](../../artifacts/hil/2026-09-26/devram-submit-20.summary.json) は 20/20 `END_SDK_RECEIVED`。中央値 29.96 秒には host 2 件/分 admission 待ちを含み、air RTT ではない。

### P7、MemberEdhoc、除外と再参加

- [ref-a console flow](../../artifacts/hil/2026-09-26/provision/ref-a-console-flow.log) は `status identity=none → keygen/PoP → provision-devcert → identity sealed → readback`。bridge も同じ手順で封印・再起動後 readback。[Node4 再 provision](../../artifacts/hil/2026-09-26/provision/ref-a-node4-console-flow.log) は別 DeviceId・公開鍵。開発 CA/SAK 秘密鍵と rlsec backup は `/tmp/routeloom-hil-2026-09-26/` の mode 0700/0600 にのみ置き、commit しない。
- 初回 MemberEdhoc は Joiner role=0 で recovery。続いて PSA AES-CCM 未配線、ZeroTouch Discover の誤破棄、colocated proxy/gateway の再入、自己 proxy down の誤分類、64-bit Site network の NodeConfig 代入、Link/End 分割送信の同時投入を順に再現・修正した。host 回帰と実機で確認。[Link の bridge/ref ログ](../../artifacts/hil/2026-09-26/diagnosis/member-bridge-chunkpaced-reset.log)、[ref ログ](../../artifacts/hil/2026-09-26/diagnosis/member-ref-a-chunkpaced-reset.log) に BOUND/REACHABLE、Link session 1。End の旧失敗は [BOOTSTRAP_PEER_FULL](../../artifacts/hil/2026-09-26/flash-ref-a-node4-endtxdiag/flash-ref-a-boot.log)。
- bridge Node1 は Site 台帳で [active](../../artifacts/hil/2026-09-26/provision/members-bridge-confirmed.json)。旧 ref Node2 は [Join request→承認→member](../../artifacts/hil/2026-09-26/provision/ref-a-loopqueue-approve.log)、confirm は `allowed_unconfirmed` のまま。revoke は [commit](../../artifacts/hil/2026-09-26/provision/ref-a-revoke.json) で RS epoch2 と GK2 を stage。[operation](../../artifacts/hil/2026-09-26/provision/ref-a-revoke-operation-initial.json) は残存 bridge 1/1 への revocation 配布 `converged`、ただし Node2 の notice は `unreachable`、erase 未確認。GK2 は後に active となったが [unknown=2](../../artifacts/hil/2026-09-26/provision/gk-after-sinkrestore.json)。追加の手動 `group_keys.rotate` は [BUSY](../../artifacts/hil/2026-09-26/provision/gk-manual-while-removal-staging.json)。
- Node2 の rlsec `0x190000..0x19ffff` だけを chip/MAC 再照合・私有 backup 後に erase（[manifest](../../artifacts/hil/2026-09-26/reprovision-reset-ref-a/manifest.json)）。Node4 の [join approval](../../artifacts/hil/2026-09-26/provision/ref-a-node4-approve.log) は request から 86 ms で `current_attempt`、実機 Joiner 完了まで約 1.8 秒。起動から scan を含めると約 24 秒。[reset readback](../../artifacts/hil/2026-09-26/provision/ref-a-node4-reboot-readback.log) に identity Node4、Site generation1、GK2。[Site members](../../artifacts/hil/2026-09-26/provision/members-node4-after-delivery.json) は Node4 を member と記録するが `allowed_unconfirmed`。
