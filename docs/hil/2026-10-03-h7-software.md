# H7 software follow-up (2026-10-03 JST)

This is a targeted software investigation, **not hardware qualification**. The
[seven-board failures](2026-10-03-h7.md) remain recorded. PM deferred hardware,
full workspace/live tests, full sanitizer ctest and firmware matrices until the
combined main round.

## Revisions and scope

Initial fetched/merged main: `497c7617f5e35fb2c49e4c3417a2226dee9705ed`, including
#254 AppObject, #255 HFINAL and the worker scheduling fix. Before completion,
main `a9f710a0b69ed094be077bcfb5337a6580624f13` (#257 H7 evidence only) was merged.
Implementation: `6cf99e78` (congested admission/retries) and `9ca6f422` (active
channel for signed late joins). No hardware was used or flashed in this PR.

Terminal quota refusal and the fourth simultaneous reply binding previously
occurred after `open_end` consumed replay state. A fresh-Link retry of the same
End frame then failed authentication without admission. Quota probing and the
existing reply reservation now precede End verification; failed End verification
rolls the reservation back. Expired terminal pins are reclaimed only after End
verification. The final existing recovery round is staggered by source within
its original five-second recovery window, avoiding simultaneous refilling of the
three-binding reply pool. Earlier rounds, attempt counts and origin deadlines
are unchanged.

A matched, authenticated gateway report now updates the Authority's operating
channel only after store commit and exact readback. Optional network-scoped
metadata (13 bytes) restores that channel after daemon restart; signed join
packages use the existing Identity fields. Failed commits, wrong request ids,
older epochs, invalid channels and conflicting committed epochs cannot publish
another active channel. The existing USB/site session and READY fences remain.

Defaults, bounded capacities, dedup/replay retention, MemberEdhoc authentication,
wire/API numbers, advertised capabilities and acceptance thresholds are unchanged.
No new manager, radio policy or hardware hook was added. The gateway256 Kconfig
choice remains available but no longer labels itself as a qualified S3 profile.
Stock S3/C3 worker-OFF gateway256 RAM-guard failures in the H7 record remain
unsupported configurations; the guard was not lowered.
