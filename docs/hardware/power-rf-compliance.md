# 電源・アンテナ・RF配備の共通確認

## 1. boardとSoCを分ける

SoCの3.3V範囲とXIAOのUSB/BAT入力は別。GPIO絶対最大値は通常動作推奨値ではない。外部sensorや表示機器の電流をGPIOから直接取らない。3V3_OUTの利用可能電流はboard、給電経路、温度、ESP32自身のpulseを差し引いて確認する。

XIAOのBATは充電池管理回路につながる。一次アルカリ電池や異なる化学種を充電経路へ接続する配線例は用意しない。二つの電源を並列にして逆流させない。認定された電源回路を使う。

## 2. 二本の乾電池を使う製品の設計例

電圧が低下する電池に対し、低静止電流DC/DC、突入・送信peak、終止電圧を含む専用電源profileを設計する。単純に新品電圧だけを見てESP32やXIAO端子へ直結しない。

平均radio電流が小さくても瞬間電流は別。DC/DCのpeak能力、battery ESR、配線抵抗、bulk capacitor、brownoutを測定する。充電用USBを同時に使うなら一次電池へ充電しない物理的分離が必要。

## 3. 電力測定

battery-sideでV(t)とI(t)を取得し、Sleep、起動、無線初期化、DATA、ACK、探索、Flash、sensorを区間分けする。E_report=積分VIを使い、3.3V側のmAhと電池側mAhを電圧変換なしに比較しない。

正常時だけでなく親不在・全channel不達・一斉再起動・低温終盤電池も測る。電池の自己放電、漏液・交換周期、温度範囲はSDKの省電力性能とは別の製品保守事項。

## 4. RF配備プロファイル

必須項目：country、board型式/revision、アンテナ型式・接続損失、認証確認記録、許可channel/PHY、tx_power_qdbm上限、適用日、承認主体、測定結果。

初期JSONの送信上限はnullで、実機TX許可ではない。SDKが自動で最大電力・高利得アンテナ・未許可channelを選ばないようにする。国コードを設定したことと、特定のLR waveform・antennaを含む設備適合は別。

RF規制の判断は国・機器・アンテナ・実装に依存する。この文書を法律上の適合証明として扱わない。申請や証明に必要な資料はメーカー・認証機関の現行資料で確認する。

## 5. アンテナ・筐体

指定アンテナの周囲に金属・battery・太い電源線を詰めず、姿勢と設置場所を記録する。U.FLを無理に抜き差ししない。Wi-Fi用とLoRa用を取り違えない。金属筐体内で試験なしに到達距離を約束しない。

二無線を近接配置する場合は、別周波数だから干渉しないとはしない。電源noise、飽和、アンテナ結合、同時TXを測る。測定のために外部の公衆無線を妨害する試験をしない。

## 6. 記録

筐体、アンテナ、電源、ケーブル、firmware、sdkconfig、SoC revision、温度、測定器、設置位置、radio設定をHIL記録へ保存する。部品交換後は関連する認定を引き継げるか明示的に再判定する。
