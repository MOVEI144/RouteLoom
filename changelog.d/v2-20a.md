### Changed

- The multi-node Owner mesh E2E moved to `host/routeloom-host/src/site/owner_mesh/`;
  run it with `cargo test -p routeloom-host --bins site::owner_mesh::`.

### Added

- `tests/e2e/scenarios.json`, the E2E scenario table, checked by
  `python3 tools/check.py scenarios`. `tools/check.py interop` fails unless
  every live PR scenario test passed.
- With `ROUTELOOM_E2E_OUT` set, each mesh E2E world writes `run.json`,
  `metrics.json` and `verdict.json` under `<dir>/<tag>/`; CI keeps them as
  the `e2e-report` artifact.
