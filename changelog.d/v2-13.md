### Added

- The site can close zero-touch intake. `join.policy.set {zero_touch_open}`
  sends a ProxyPolicySet (authority envelope type 9) to every member proxy
  until it acknowledges the generation as stored. Each proxy keeps it in the
  RLPP1 record. A closed proxy gives no OFFER to unassigned devices and still
  serves devices that already hold this site's membership. `join.policy.get`
  and `site.status` report applied, pending and unknown proxies and
  `radio_distributed_generation`.
- A revoked NodeId can come back. The site reissues it only above the revoked
  generation and marks the RRS1 entry (object version 2) with
  `readmit_gk_epoch`. Receivers accept group frames from that sender from
  that GK epoch on. RRS1 version 1 reads as readmit 0. While a GK rotation or
  cutover is staging, readmit answers BUSY.
- Frame types 64–66 are registered for AppObject. Terminals answer
  UNSUPPORTED until the object transfer ships.

### Changed

- Wire forward compatibility inside major 2:
  - A frame with a newer minor is accepted.
  - Frame types 64–95 are extension types. Relays forward them, and a
    terminal that does not implement one answers TransitFailure `UNSUPPORTED`
    (reason 12).
  - Header byte 9 is now the traffic byte. Bits 0–1 set the relay's DRR
    class (Normal, Bulk or Urgent), and the other bits are ignored.
  - Flags stay strict, and the existing golden vectors are unchanged byte
    for byte.
- The RLV1 local revocation record moves to schema 2, which range-checks the
  holdoff (60 s to 1 h). Schema 1 records still load.
- The site store moves to schema 3, which adds `policy_acks`. The migration
  runs forward only and first keeps a `<store>.schema2.bak` copy.
