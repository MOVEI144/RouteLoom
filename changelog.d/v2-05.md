### Added

- Resource profiles: the component Kconfig choice *Resource profile*
  (`endpoint`, `relay`, `gateway_small`, `gateway`, `full`) and host CMake
  `-DROUTELOOM_RESOURCE_PROFILE=` size the session bank, the route table and
  the optional features from `routeloom/profile.hpp`. End-to-end sessions are
  8 on endpoint/relay, 64 on `gateway_small`, 128 on `gateway`/`full`; a full
  end table evicts the oldest idle context (never one with a seal in flight)
  and RLRES1 restores it. `CoordinatorSnapshot::end_evictions` counts them.
- Device role Kconfig choice `ROUTELOOM_ROLE` (endpoint, relay, gateway). A
  configured or stored role above the image role is refused before RF starts
  with `RESOURCE_PROFILE_ROLE_MISMATCH`; a higher grant received during join
  enters membership recovery.
- USB bridge feature options `ROUTELOOM_USB_NODE_STATUS`,
  `ROUTELOOM_USB_GATEWAY_ENDPOINT`, `ROUTELOOM_USB_GROUP` and
  `ROUTELOOM_USB_OBSERVATION`. A compiled-out feature's `attach_*()` returns
  Unsupported and its HelloAck capability bit stays clear.

### Changed

- **Breaking:** the image role no longer follows the ESP-IDF project name
  (`ROUTELOOM_REFERENCE_IMAGE` is removed). Set `CONFIG_ROUTELOOM_ROLE_*` and
  `CONFIG_ROUTELOOM_RESOURCE_PROFILE_*`; the firmware defaults are relay for
  `reference_node`/`bench_node`, endpoint for the example, and
  `gateway_small` (ESP32-C3) or `gateway` for `bridge_node`.
- **Breaking:** `EspNowSecurityOwner::Config::gateway` is replaced by
  `Config::role` (`routeloom::profile::Role`).
- The ESP32-C3 bridge leaves node status (0x40-0x42) and the explicit
  gateway/config endpoints (0x10-0x25) out by default; enable
  `CONFIG_ROUTELOOM_USB_NODE_STATUS` / `CONFIG_ROUTELOOM_USB_GATEWAY_ENDPOINT`
  before setting capability bits 6 or 3-4 on that image. The ESP32-C6 bridge
  uses the 256-record dedup pool.
- Only gateway profiles run the join relay gateway; endpoint-profile nodes
  never proxy joins. The dedup capacity choice gains *resource profile
  default* (32 on endpoint/gateway_small, 96 otherwise); the old
  `CONFIG_ROUTELOOM_DEDUP_PROFILE_*` entries still pin a size.
- A deep-sleep RTC session image written under another resource profile is
  refused and the node resumes cold.
