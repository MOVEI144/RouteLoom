### Added

- `CONFIG_ROUTELOOM_CONFIG` (the remote-config target) is available on
  DevRam and MemberEdhoc nodes, not only LegacyFixture. A Member binds the
  SDK-namespace journal to its adopted site once the membership is adopted
  and accepts only COSE permits signed by the site's authority key; DevRam
  verifies the development permit key derived from its PSK, issued by
  `CONFIG_ROUTELOOM_CONFIG_AUTHORITY`. The RLF1 floor is provisioned when
  the journal binds.
- `Device::gateway()`: explicit gateway delivery (resolve a named gateway,
  send to it) for any node on the Device boot path. A USB gateway attaches
  the same component for `gateway_endpoint_v1`.

### Changed

- The USB gateway and config endpoints (HelloAck bits 3 and 4) are attached
  inside `Device::begin()`, so every image and the host mesh harness use the
  same wiring.
- CI builds the explicit gateway, remote config, maintenance and deep-sleep
  cells on DevRam and MemberEdhoc. One LegacyFixture compatibility cell
  (`bridge_node-esp32c3-normal-observe-off`) remains until LegacyFixture is
  removed.

### Fixed

- The host config lane signs Member permits for the low word of the
  gateway's session network. A Member gateway reports the full site network,
  so issuance to a Member was refused before.
