### Added

- `CONFIG_ROUTELOOM_CONFIG` (the remote-config target) is available on
  DevRam and MemberEdhoc nodes, not only LegacyFixture. A Member binds the
  SDK-namespace journal to its adopted site once the membership is adopted
  and accepts only COSE permits signed by the site's authority key; DevRam
  verifies the development permit key derived from its PSK, issued by
  `CONFIG_ROUTELOOM_CONFIG_AUTHORITY`. The RLF1 floor is provisioned when
  the journal binds.
- Manual channel plans on MemberEdhoc (`CONFIG_ROUTELOOM_MIGRATION`): every
  member runs the migration participant and verifies plans with the adopted
  site's key; the USB gateway is the site's plan authority and admits
  SAK-signed plans from the host over `channel_plan_v1` (HelloAck bit 13,
  HostOps 0x68/0x69). A member re-adopts its site on the plan's channel
  after a reboot, and the join coordinator follows each verified switch.
- API1 `site.channel_plan.status`, `site.channel_plan.offer` and
  `site.channel_plan.release`, and `routeloomctl site channel-plan
  status|offer|release`: the host builds the next plan from the gateway's
  report, signs it with the site key, sends it, and releases the commit
  once the gateway's connected peers answered READY.
- `Device::gateway()`: explicit gateway delivery (resolve a named gateway,
  send to it) for any node on the Device boot path. A USB gateway attaches
  the same component for `gateway_endpoint_v1`.

### Changed

- The USB gateway and config endpoints (HelloAck bits 3 and 4) are attached
  inside `Device::begin()`, so every image and the host mesh harness use the
  same wiring.
- CI builds the explicit gateway, remote config, maintenance and deep-sleep
  cells on DevRam and MemberEdhoc. One LegacyFixture compatibility cell
  (`bridge_node-esp32c3-normal-observe-off`) remains until LegacyFixture is
  removed.

### Fixed

- The plan authority holds its connected peers in the READY gate from
  OFFER through RELEASE and terminal result. It rejects an offer its own
  radio cannot prepare and ignores reports for another plan or epoch.
  Observe mode does not advertise manual issuance. The host can
  release a held plan after restarting by reading a fresh gateway report.
- The migration agent's TimeSync reached only the first peer when the radio
  had one frame in flight; the remaining peers now get theirs on the next
  polls. Object delivery dedup is per sender, so equal READY reports from
  two members both count. The live channel reconcile waits while the Owner
  holds the channel for a re-join scan.

- The host config lane signs Member permits for the low word of the
  gateway's session network. A Member gateway reports the full site network,
  so issuance to a Member was refused before.
- `Device::gateway()` retries Service sink attachment after a callback
  prevents the first attempt, allowing subsequent explicit gateway sends.
