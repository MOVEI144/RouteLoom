### Added
- Manifest-checked candidate release builds, complete source and host/firmware
  artifacts, checked NOTICE/SBOM inventories, SHA-256 provenance, and an optional
  maintainer-selected signing hook that rejects the meshviz development key.
- Product-image development-key/provider checks, N-1 record/HostLink checks,
  and byte-preserving RC promotion with explicit H4 qualification requirements.

### Fixed
- Candidate build jobs use one prepared commit SHA, including when a tag moves.
- Release packaging binds flash arguments to the inspected app and chip and
  records hashes for every flash image. Signing hooks cannot change candidate
  bytes or publish symbolic links as signing outputs.
- Release assets and binary archives include locked dependency license texts.
