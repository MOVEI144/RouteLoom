### Added

- The Site Authority can sign a canonical manual channel plan through API1
  `site.channel_plan.sign` or `routeloomctl site channel-plan`. The result is a
  signed artifact for gateway admission; this command does not dispatch it.

### Security

- Portable remote configuration and channel plan verification can use the
  adopted site's signing key. The host signs site configuration permits with
  that key and rejects a gateway session for another site network.
