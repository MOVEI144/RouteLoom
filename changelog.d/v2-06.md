### Changed

- The portable `MeshNode` implementation is split from `src/node.cpp` into
  functional translation units (`src/node_*.cpp`) with no behaviour change.
  Builds that list the core sources by hand instead of using
  `components/routeloom/CMakeLists.txt` must add the new files.
- Firmware `app.bin` budgets in `tools/ci/cells.json` are raised to the
  measured size after the split (+1.1 to +2.3 KB, 0.08 to 0.17 % per cell):
  code that was inlined inside one `node.cpp` is now called across
  translation units. Static RAM and RTC/LP RAM are unchanged in every cell,
  so the RAM guards and `static_free_min` budgets stay as they were.
